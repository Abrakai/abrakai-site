## Co-Space 完整操作

1. 開啟 https://abrakai-studio.com/tools/co-space/ ，用既有方式進入講師模式；手冊不提供通行碼。
2. 先按「匯出」，保存原本卡片庫 JSON。卡片存在目前瀏覽器 LocalStorage；不是雲端同步。
3. 從教材頁下載 `book-course-navigation-cards.json`，在 Co-Space「匯入」選取檔案。現有匯入會替換整個卡片庫，不會合併；務必先備份。
4. 全班先掃教材頁的課程 QR；再依序投影六張步驟導覽卡，提示學員目前做到哪一步。
5. 導覽卡內容是教材入口與操作提醒，不能代替完整 Prompt。完整 V3.0 文字都在教材頁，可直接按複製。
6. Co-Space 卡片 QR 仍採現有壓縮網址機制；正式取得全文以教材頁為主。可用飛鴿傳書收集課堂回饋，但不要輸入敏感資料。
7. 課後匯出本次卡片；要還原原本卡片庫，重新匯入課前保存的 JSON。

目前六段 Prompt 長度均低於 Co-Space 1,800 字匯入上限，最長約 1,753 字；後續加長可能被截斷。長內容放進 QR 也會增加密度，因此本課採教材網址分享。這不是 Worker／KV 短鏈服務；不需要宣稱已有雲端卡片管理。

## 每一步的授課做法

- Step 1：先做素材盤點；未確認權利不進行公開網站生成。
- Step 2：看 AI 輸出並回原資料核對；看不清楚的內容補素材，不能讓 AI 猜。
- Step 3：確認依裝置確認頁數內容順序與行動按鈕；先確認企劃再產生程式。
- Step 4：複製 Prompt 3，取得完整 HTML。如果 AI 只回部分片段，請它補成可保存的完整檔；檔名保存為 index.html，不能保留 Markdown 程式碼圍欄。
- Step 5：一次加入一項互動；不需要為了特效犧牲閱讀、手機速度或圖片合法性。
- Step 6：列出問題位置、原因、修改及測試結果；只修必要範圍。

## HTML、發布與備份

電腦可把 AI 交付的完整 HTML 下載／保存為 index.html，雙擊開啟或使用現有預覽環境驗證。手機若不能直接開啟本機 HTML，先保留檔案，使用已發布範例理解互動，課後以電腦完成。

要發布到 Neocities，僅上傳可公開 HTML 及其相依素材至自己的網站根目錄，確認 HTTPS 網址能打開再分享 QR；若是更新已有網站，先備份原檔，再只覆蓋本次更新包列出的檔案。不要把原始碼、交接文件、帳密或 API Key 上傳。

原始碼預設放 GitHub Private；純前端 HTML 送到瀏覽器後仍可被檢視，不能靠 Private Repository 保護公開程式中的機密。會員、正式權限與付費內容需另做後端架構。本堂課不新增這些功能。

課後至少保存素材、確認過的內容、最終 HTML、完整 Prompt 及 Co-Space JSON。QR 分享的是公開入口，不能當作加密或登入保護。
