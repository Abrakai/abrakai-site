# 一本書，讓 AI 幫您做成會翻頁的銷講網站

阿布拉.凱工作室・AI 小教室｜課堂提示詞與講師手冊 V2.0

## 課程成果

學員將一本書或刊物整理成「書籍精華導讀＋翻頁試閱＋作者介紹＋行動按鈕」的一頁式網站。網站讓讀者在約 3 分鐘內理解書籍主題、適合對象、核心觀點與下一步行動。

這不是完整電子書。公開內容以摘要、導讀、自製圖像及少量短引文為主。

## 50～60 分鐘課程流程

| 時間 | 教學內容 | 課堂產出 |
|---|---|---|
| 0～5 分鐘 | 完成品展示與課程目標 | 學員理解最後成果 |
| 5～10 分鐘 | 電腦、手機兩條路線 | 選擇今天的操作方式 |
| 10～16 分鐘 | 素材與著作權邊界 | 完成素材清單 |
| 16～25 分鐘 | Prompt 1：資料辨識與重點萃取 | 書籍資料表與核心觀點 |
| 25～33 分鐘 | Prompt 2：銷講架構與翻頁腳本 | 八頁導讀腳本 |
| 33～43 分鐘 | Prompt 3：生成單一 HTML | 可離線開啟的網站 |
| 43～49 分鐘 | Prompt 4：圖片、動態與聲音 | 主題化互動效果 |
| 49～54 分鐘 | 測試、修正與公開檢查 | 通過發布清單 |
| 54～60 分鐘 | 上線、網址與 QR Code | 可分享的網站網址 |

40～50 分鐘版本可直接提供已整理的書籍資料與備援 HTML，省略等待 AI 生成的時間。

## 操作設備建議

### 建議使用電腦

- 可同時查看書籍圖片、AI 回覆、HTML 與瀏覽器預覽。
- 複製長提示詞、修改檔名及整理圖片較容易。
- 適合完成翻頁、鍵盤操作、手機滑動、圖片與音效測試。
- 適合正式上傳 Neocities、Cloudflare Pages 或其他靜態網站服務。

### 手機可完成的快速版

- 拍攝封面、目錄、作者介紹及 5～8 頁重點。
- 讓 AI 產生摘要、八頁腳本與單頁網站內容。
- 使用支援網頁預覽或分享網址的 AI 工具，先完成可上下滑動的導讀頁。
- 若要使用單一 HTML，可將 `index.html` 上傳至靜態網站服務，再分享網址或 QR Code。

手機適合快速完成內容與分享。需要整理多張圖片、修改程式或除錯時，電腦會更穩定。

## Prompt 0：先確認素材與公開範圍

```text
你現在是一位出版內容授權檢查助理。

我會提供一本書或刊物的素材清單。請協助我判斷哪些內容適合放入公開的「書籍精華導讀網站」。

請注意：
1. 不判定法律責任，也不要聲稱某內容一定合法。
2. 將素材分為「可直接使用」「需要授權或確認」「不建議公開」三類。
3. 公開網站以摘要、導讀、自製圖像及少量短引文為主。
4. 不公開整本書、大量連續頁面、付費內容或未取得授權的完整圖片。
5. 若資料不足，明確寫出需要向作者、出版社或權利人確認的事項。

請輸出：
A. 素材盤點表
B. 建議公開範圍
C. 必須補充的來源與署名
D. 需要人工確認的權利問題

以下是我的素材：
【貼上素材清單】
```

## Prompt 1：辨識內容並擷取重點

```text
你現在是一位嚴謹的出版編輯與內容整理師。

我將提供一本書或刊物的封面、目錄、作者介紹及部分內頁照片。請先辨識資料，再整理適合製作「書籍精華介紹網站」的內容。

請遵守以下規則：
1. 只能使用我提供的資料，不得自行補寫書中不存在的內容。
2. 看不清楚、無法確認或缺少的資料，請標示「需要確認」。
3. 將原文引用與你的摘要分開。
4. 原文引用保持簡短，並標示來源頁面或圖片編號。
5. 不要大量抄錄原書，以摘要、改寫與導讀為主。
6. 使用繁體中文。

請依下列格式輸出：
A. 書名、副標題、作者、出版社與出版資訊
B. 全書主要讀者
C. 作者寫作目的
D. 全書主題摘要，100～150 字
E. 5～8 個重要觀點，每點包含「標題、摘要、資料來源」
F. 可安全使用的短句或短引文
G. 需要人工再次確認的資料
H. 建議放入網站的圖片清單
```

### 人工檢查

- 姓名、數字、年代與專有名詞。
- 摘要是否忠於原書。
- AI 是否把推測寫成事實。
- 引文是否過長。
- 資料不足處是否清楚標示。

## Prompt 2：規劃銷講架構與八頁翻頁內容

```text
請根據剛才已經人工確認的書籍資料，擔任書籍行銷編輯與網站內容企劃。

目標是規劃一個「書籍精華導讀＋可翻頁試閱＋作者介紹＋行動按鈕」的一頁式網站。這不是完整電子書，不可公開整本內容。

網站對象：第一次認識這本書的讀者。
網站目標：讓讀者在 3 分鐘內理解這本書在談什麼、適合誰、重要觀點，以及下一步如何閱讀、購買或聯絡作者。

請輸出：
1. 網站主標題
2. 一句副標題
3. 120 字以內的書籍簡介
4. 三個閱讀收穫
5. 八頁翻頁導讀腳本，每頁包含：
   - 頁面標題
   - 60～100 字內容
   - 可使用的短引文或關鍵句
   - 建議搭配的圖片或視覺符號
6. 作者介紹，120 字以內
7. 適合哪些讀者
8. 行動按鈕文字及真實目的地，例如購書頁、作者官網或聯絡方式
9. 資料來源與著作權提醒

寫作原則：
- 使用繁體中文。
- 語氣清楚、有質感，不浮誇。
- 每一頁只傳達一個主要觀點。
- 先建立讀者的問題，再說明書籍能帶來的理解或方法。
- 不得捏造推薦人、銷售數字、獎項或讀者評價。
- 缺少網址或作者資料時，標示「待提供」。

以下是已確認的書籍資料：
【貼上 Prompt 1 經人工確認後的結果】
```

## Prompt 3：生成單一 HTML 翻頁網站

```text
請根據以下已確認的書籍網站企劃，製作一個精美、手機優先的一頁式書籍介紹網站。

技術規格：
1. 只輸出一個完整的 index.html。
2. CSS 與 JavaScript 全部寫在同一個 HTML 內。
3. 不使用資料庫、登入、後端或 API。
4. 不得放入任何 API Key、Token、密碼、會員資料或私人紀錄。
5. 不依賴外部 JavaScript 函式庫，離線開啟也能操作。
6. 圖片若由我提供，請轉成 Base64 後嵌入 HTML；沒有圖片時使用排版、色彩與 CSS 圖形完成設計。

網站內容：
- 書籍主視覺、書名、副標題與簡介
- 三個閱讀收穫
- 八頁精華翻頁區
- 作者介紹
- 適合讀者
- 資料來源與著作權聲明
- 購書、閱讀原文或聯絡作者按鈕

翻頁功能：
- 電腦可點擊上一頁、下一頁
- 支援鍵盤左右方向鍵
- 手機支援左右滑動
- 顯示目前頁碼與總頁數
- 第一頁不能再往前，最後一頁不能再往後
- 翻頁動畫自然，不影響閱讀

設計要求：
- 視覺風格依書籍封面與主題決定，不套用制式模板。
- 正文字級至少 16px，手機不得出現水平捲動。
- 暗底使用亮字，亮底使用暗字，所有內容保持清楚對比。
- 尊重 prefers-reduced-motion 設定。
- 使用語意化 HTML、圖片替代文字及鍵盤焦點樣式。
- 所有按鈕都必須有真實功能或真實網址。

輸出前請自行檢查：
- HTML 標籤完整
- JavaScript 沒有語法錯誤
- 手機版文字不重疊
- 翻頁、連結及按鈕可操作
- 頁面沒有待補文字或無效的 # 連結

以下是已確認的網站企劃：
【貼上 Prompt 2 經人工確認後的結果】
```

## Prompt 4：增加圖片、動態與聲音

```text
請在不改變既有書籍內容與翻頁功能的前提下，提升這個單一 HTML 網站的互動表現。

請加入：
1. 首頁主視覺的輕量進場動畫。
2. 翻頁時的層次、光影或紙張感，但不得造成暈眩或影響閱讀。
3. 每一頁可放一張與該觀點直接相關的圖片，圖片必須有來源、授權或由我提供。
4. 可關閉的環境音效或翻頁音效。預設靜音，必須由使用者主動開啟。
5. 音效按鈕要顯示目前狀態，並提供停止功能。
6. 尊重 prefers-reduced-motion；使用者要求減少動態時，停用非必要動畫。
7. 手機效能優先，不加入大量粒子或高耗能背景效果。

視覺原則：
- 效果必須服務內容，不遮住文字。
- 暗底亮字、亮底暗字。
- 不使用來源不明的網路圖片或音樂。
- 保留鍵盤操作、手機滑動與無障礙焦點。

請輸出更新後的完整 index.html，不要只輸出局部程式碼。

以下是目前可正常使用的 index.html：
【貼上完整 HTML】
```

## Prompt 5：發布前除錯與修正

```text
你現在是一位前端網站測試工程師。請檢查我提供的單一 index.html，找出會影響公開發布的問題，並直接回傳修正後的完整 HTML。

請依序檢查：
1. HTML、CSS 與 JavaScript 語法。
2. 上一頁、下一頁、頁碼與邊界狀態。
3. 鍵盤左右方向鍵。
4. 手機左右滑動與 390px 寬度畫面。
5. 文字是否重疊、截斷或對比不足。
6. 圖片是否有替代文字、來源與載入失敗的備援。
7. 音效是否預設靜音，並可隨時關閉。
8. 是否尊重 prefers-reduced-motion。
9. 是否存在無效的 # 連結、待補文字或錯誤網址。
10. 是否包含 API Key、Token、密碼、會員資料或不應公開的資訊。

輸出格式：
A. 問題清單
B. 修正內容摘要
C. 修正後的完整 index.html

以下是要檢查的 HTML：
【貼上完整 HTML】
```

## 發布前人工檢查清單

- 書名、作者、出版社、年代及引用來源正確。
- 封面與內頁圖片已取得使用權或確認授權條件。
- 網站沒有公開整本書或大量連續內頁。
- 所有購買、閱讀、聯絡按鈕均連到正確網址。
- HTML 不含 API Key、Token、密碼、會員資料及私人紀錄。
- 電腦、390px 手機寬度及至少兩種瀏覽器都已測試。
- 動畫不影響閱讀，音效預設關閉且可以停止。
- 已保留本機 HTML、部署 ZIP 與目前線上版本備份。

## 課堂備援

1. 預先準備已確認的書籍資料。
2. 預先準備可離線開啟的完成版 HTML。
3. 預先準備公開網址及 QR Code。
4. AI 生成等待超過兩分鐘時，切換備援檔繼續教學。
5. 網路中斷時，改用本機 HTML 示範翻頁與手機畫面。
