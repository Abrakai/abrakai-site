使用裝置語音，音色清單取決於手機；裝置若提供男聲或女聲，會一併列出；沒有提供的音色，網頁無法新增。請逐一試聽，不以音高假冒男聲或女聲。音高調整不會改變說話者或提升語音品質。自然連讀減少中英混合句的切換，獨立英文句子仍使用英文語音。建議用 Safari 開啟並保持頁面在前景。暫停後繼續會從目前片段重讀。中文文章的數字、百分比與算式會先整理讀法；登記字號逐位朗讀，英文詞句使用英文音色。只調整送去朗讀的讀法，不改寫或重算原文。

「驗證／更新音色」查詢模型與音色，ElevenLabs另嘗試查詢訂閱額度，不生成語音、不產生語音生成字數或 token。它仍是 API 請求，可能受到查詢限流或廠商政策限制。點「生成並朗讀」才會要求 AI 生成，包含預先準備的下一片段；可能使用免費額度或計費。
