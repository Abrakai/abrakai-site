阿布拉.凱工作室官網 V2.3.0
「房產安心查｜不動產實用查詢工具箱」更新與部署說明

一、本次更新內容
1. 新增公開免費頁面：real-estate/property-tools/
2. 整理 14 個不動產查詢入口，共 5 大分類。
3. 新增關鍵字搜尋與分類篩選。
4. 使用阿布拉.凱 3D 可愛公仔作為頁面引導形象。
5. 官網首頁導覽、房產服務區及頁尾新增「房產安心查」。
6. 「AI 與實用工具中心」新增房產安心查卡片。
7. sitemap.xml 新增工具頁網址。
8. 網站清單集中於 tools-data.js，方便日後自行更新與搬移。

二、架構與資安判定
- 類型：公開網站中的免費靜態工具頁。
- 對象：一般民眾、房產買賣雙方及工作室粉絲。
- 外部存取：需要；點擊後前往原查詢網站。
- 原始碼：建議持續存放於 GitHub Private Repository。
- 敏感資訊：本功能不含 API Key、Token、密碼、會員資料或資料庫憑證。
- 後端需求：第一版不需要後端、登入、資料庫、金流、訂閱或排程。
- 隱私：不讀取、不傳送、不保存訪客在外部網站輸入的地址、地號或個人資料。
- 未來移植：保留 real-estate/property-tools/ 完整資料夾即可模組化搬移。

三、上架方式
方案 A｜完整包
直接將完整包內容上傳至 Neocities 網站根目錄。

方案 B｜最小更新包（建議先測試）
將更新包解壓縮後，維持資料夾結構覆蓋至網站根目錄。
會更新：
- index.html
- styles.css
- sitemap.xml
- tools/index.html
- real-estate/property-tools/（新增完整資料夾）

四、上架前安全步驟
1. 先下載目前線上網站完整備份。
2. 確認備份檔可以正常解壓縮。
3. 先上傳最小更新包並測試首頁、工具中心與新頁面。
4. 測試手機版搜尋、五個分類與所有外部按鈕。
5. 若有異常，可用更新前備份覆蓋還原。
