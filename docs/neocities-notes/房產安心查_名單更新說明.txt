不動產實用查詢工具箱｜自行更新說明

一、這個模組放在哪裡
本工具完整放在：
real-estate/property-tools/

未來搬到新網站時，只要保留此資料夾的完整結構，再依新網站位置調整頁首與頁尾的相對路徑即可。

二、日後新增、刪除或修改查詢網站
請編輯：
real-estate/property-tools/js/tools-data.js

網站清單都集中在 tools 陣列中。每一筆資料包括：
- id：不重複的英文代號
- category：分類代號
- name：網站顯示名稱
- url：完整網址，請保留 https://
- description：給一般民眾看的用途說明
- sourceType：official、professional 或 community
- sourceLabel：政府官方、專業平台或民間資料・需複核
- keywords：搜尋用關鍵字，以空格分開

可用的 category：
- land-records：地籍與謄本
- price-tax：房價與稅務
- building：建築相關查詢
- land-use：國土與土地使用
- risk：土地風險與環境

新增網站時，複製既有的一組 { ... }，再修改各欄位即可。
刪除網站時，刪除該網站完整的 { ... } 區塊，並留意前後項目的逗號。

三、更新「最近核對日期」
同一檔案最上方有：
updatedAt: "2026-09-20"

確認連結後請改成新的西元日期，格式固定為 YYYY-MM-DD。

四、修改網頁名稱或文案
主要檔案：
real-estate/property-tools/index.html

目前使用：
主名稱：房產安心查
副標題：不動產實用查詢工具箱

五、資安與隱私設計
- 本頁為純靜態前端，不含 API Key、Token、密碼或資料庫憑證。
- 不會讀取或保存訪客在外部網站輸入的地址、地號或個人資料。
- 外部網址以新視窗開啟，並使用安全的 rel 屬性。
- 民間事故屋資料已清楚標示「需複核」，不可作為單一交易判斷依據。

六、上架前檢查
1. 手機與電腦都打開一次。
2. 測試搜尋與五種分類按鈕。
3. 逐一確認所有「前往查詢」按鈕。
4. 確認首頁、工具中心與房產稅務專題可正常返回。
5. 部署時請整包上傳，不要遺漏 css、js 或 assets 資料夾。
